🌐 내 나라 말로 보기 (크롬 번역)

🙏 자신이 편한 모국어나 영어로 선택해서 진행해 주세요.

이 앱은 크롬(Chrome)에 들어 있는 번역 기능을 써요. 100개가 넘는 언어를 고를 수 있어요.

🤖 안드로이드 (크롬)
오른쪽 위 ⋮ 메뉴 → 번역… → 아래 번역 막대의 ⋮ → 다른 언어 선택 → 내 언어 고르기
🍎 아이폰 (크롬)
아래쪽 ⋯ 메뉴 → 번역 → 번역 막대의 ⚙️ 또는 언어 이름 → 내 언어 고르기
💻 컴퓨터 (크롬)
주소창 오른쪽 번역 아이콘 또는 화면에서 마우스 오른쪽 클릭 → 번역 → ⋮ → 다른 언어 선택
  • ✍️ 답은 내 나라 말로 편하게 써도 괜찮아요. 내가 고른 언어가 이야기에 자동으로 함께 기록돼요.
  • 👀 다른 사람의 이야기도 크롬 번역을 켜 두면 내가 고른 언어로 바뀌어 보여요.
  • 🙂 이름은 번역되지 않고 그대로 보여요.

🧭 문화적응이란?

심리학자 존 베리(John W. Berry)는 새로운 나라에 사는 사람의 마음을 두 가지 질문으로 살펴봤어요.

❶ 내 나라의 문화(언어·음식·전통)를 지키고 싶나요?
❷ 한국 사람들, 한국 문화와 어울리고 싶나요?

두 질문의 답에 따라 4가지 유형이 나와요. 좋고 나쁨이 아니라 지금 내 마음의 위치예요. 마음은 계속 움직여요 🌱

✍️ 나의 이야기 쓰는 법

  1. 🙋
    누구인지 고르기
    남자·여자·가족 중 하나를 눌러요.
  2. ✏️
    이름 쓰기
    가족이라면 가족 이름과 역할도 적어요. 여러 명이면 ➕ 추가하기를 눌러요.
  3. 🚀
    여정 시작하기
    버튼을 누르면 질문 화면으로 넘어가요.
  4. 🧭
    유형 고르기
    4개 카드 중 지금 마음과 가까운 것을 눌러요. 잘 모르겠으면 🤔 간단 체크를 해 보세요.
  5. 💬
    질문 4개 답하기
    짧게 써도 괜찮아요. 빈칸으로 두어도 돼요.
  6. 💌
    이야기 공유하기
    버튼을 누르면 모두의 이야기에 올라가요.

💌 모두의 이야기 사용법

  • 🔎 위쪽의 유형 버튼을 누르면 같은 유형의 이야기만 모아 볼 수 있어요.
  • ❤️ 공감을 누르면 마음을 전할 수 있어요. (한 이야기에 한 번)
  • ⋯ 버튼을 누르면 수정하기·삭제하기가 나와요. 삭제하려면 선생님께 받은 비밀번호가 필요해요.
  • 🏡 같은 가족 이름으로 쓰면 하나의 가족 카드로 모일 수 있어요. 합치기 전에 꼭 물어봐요.
  • 🔤 이야기 번역에서 한국어나 English를 누르면, 여러 나라 말로 쓴 답변이 모두 한 언어로 바뀌어요. 원문도 아래에 함께 보여요. (진행자·강사님께 추천)
  • 🌐 크롬 번역을 켜면 다른 사람의 이야기도 내가 고른 언어로 읽을 수 있어요. 오른쪽 위 🌐를 눌러 보세요.
